### New Issues

No Critical, no Important.

- **N-1 (Minor, design cost already noted by the implementer).** `CsvFormats.kt:194` splits on every comma, so a legitimate URI containing a comma (`https://a.example/x?q=1,2`, common in map and tracking URLs) becomes URL `https://a.example/x?q=1` plus a note line `URL: 2`. Silent data mangling on a case where the old code was right for a single URI. Fix (cheap, same fixture/test style): split only on a comma followed by optional spaces and a URI scheme, e.g. `Regex(",\\s*(?=[A-Za-z][A-Za-z0-9+.-]*://)")`, or keep the cell whole when no piece after the first starts with a scheme (so `androidapp://...` still splits). Add a test `login_uri = "https://a/x?q=1,2"` -> one URL. At minimum keep it in the «Pendiente de confirmar» list (it is) and add it to the Task 12 phone check. Because the delimiter itself is unconfirmed, a regex that only splits before a scheme is also the safer guess.
- **N-2 (Minor).** `ImportKdf.kt:171-173`: any `IllegalArgumentException` from `SCrypt.generate` is reported as «too big», which is false for a real bug (for example a wrong `length` or a null). Today `checkScrypt` runs first, so only the RFC 7914 case can reach it, which is why it is acceptable. Fix: narrow the belt to the message/case (`n >= 1 shl 16 && r == 1`) or keep the mapping and add a comment that other callers must pre-check. Also a hostile `login_uri` cell is truncated at 64 KiB + 1 by the CSV reader, so a cell of thousands of commas/spaces followed by a URL can lose that URL silently (no skip row). Hostile-only and harmless; no change needed.
- **N-3 (Minor, test gap).** No direct test for `importBase64(spare = n)`: `""`, `"="`, `"A==="`, `"AA=A"`, `"AA=="`/`"AAA="` sizes with the spare bytes zero and a correct `size`. The Aegis fixture covers only the padding of its own `db`. Add a small `ImportKdfTest` case.
- **N-4 (Minor, wording).** `BitwardenCryptoTest.passwordAndKeysAreZeroed` loops with `Triple(file, right, wrongCount)` whose counts (9/6, 10/7) are only explained in a comment; fine, but the next change to the reader will need both numbers updated. No fix needed.
- **N-5 (Minor, style).** Stray blank line before the closing brace in `AegisCryptoTest.kt` and `BitwardenCryptoTest.kt` (lines after the last test); ktlint/detekt may flag it.
