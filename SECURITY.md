# Política de seguridad

## Reportar una vulnerabilidad

No publiques contraseñas, frases semilla, tokens, claves privadas ni detalles de un exploit sin corregir en una incidencia pública.

Para un informe sensible, utiliza la función **Private vulnerability reporting** de GitHub si está habilitada en este repositorio. Si no aparece, escribe a seguridad.egt17baa@gmail.com antes de publicar los detalles. Incluye la versión o commit afectado, el impacto, los pasos mínimos para reproducirlo y una propuesta de mitigación si la conoces.

## Alcance

Se agradecen informes sobre la aplicación Android, el cifrado y la bóveda, las importaciones/exportaciones, el manejo de datos sensibles, dependencias y flujos de GitHub Actions.

## Expectativas y limitaciones

- No envíes datos reales de la bóveda ni frases semilla para demostrar un fallo.
- No se promete un plazo de respuesta ni una recompensa.
- La ausencia de vulnerabilidades conocidas no significa que la aplicación haya pasado una auditoría independiente.
